Forge3D 0.122 Beta comes with a new companion app, **Forge3D Scenery**, for buildings, rocks, terrain and trees (its own download: see the Forge3D Scenery 0.5.0 release). Forge3D itself is unchanged to use: it opens the scenery Scenery makes. Still a beta: keep copies of models you care about.

## Download

- **Forge3D-0.122.0-Setup.exe**: the installer (recommended). Installing over 0.117 updates it in place.
- **Forge3D-0.122.0-portable.zip**: unzip anywhere and run `Forge3D.exe`.

Windows 10 or 11, 64-bit. **"Windows protected your PC"?** Click **More info**, then **Run anyway** (the installer isn't code-signed yet).

## New since 0.117

- **Forge3D Scenery**, a companion app for scenery, built on the same engine and the same .f3d files: a model opens in either app.
- Forge3D opens models with Scenery's buildings, rocks, terrain and trees. They're shapes like any other here (move, cut, combine, print them), and their descriptions come along when saved, so Scenery can still change them.
- Check for Updates looks only at Forge3D's own releases, so it never offers a Scenery release.
- Under the hood: the 3D view, themes, log and crash handler moved into a library both apps share.

## File format

Now 58 (was 54 in 0.117): a shape can carry a Scenery building, rock, terrain or tree description. Files saved by 0.122 need 0.122 or later; 0.122 opens all older files.
