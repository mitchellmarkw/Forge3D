The first public release of Forge3D: free 3D design for 3D printing on Windows, mixing the ease of 3D Builder with FreeCAD-style parametric design. This is a **beta**: it works, but expect rough edges, and keep copies of models you care about. Sculpting is still to come.

## Download

- **Forge3D-0.25.0-Setup.exe**: the installer (recommended). Adds Forge3D to the Start menu, lets .f3d files open in it, and can be removed from Windows Settings → Apps.
- **Forge3D-0.25.0-portable.zip**: no installing; unzip anywhere and run `Forge3D.exe`.

Windows 10 or 11, 64-bit.

**"Windows protected your PC"?** The installer isn't signed with a paid certificate yet, so Windows SmartScreen doesn't recognise it. Click **More info**, then **Run anyway**.

## What it can do

- Shapes (box, cylinder, sphere, cone, torus, tube, wedge, pyramid, text), moved, turned and resized with handles or by typing sizes.
- Merge, Subtract, Intersect, Split, Mirror, Align, Group; every result stays editable.
- Parametric design: a step history with a rollback bar, a 2D sketcher with dimensions, Pad, Pocket, Revolve, Groove, Holes, Shell, rounded and chamfered edges, Follow grooves along a path on a surface, and linked patterns.
- Emboss words, logos or photos onto any surface, even round curves.
- Print: Lay on Face, Sit on Plate, export STL / 3MF / OBJ, or Send to Slicer. Imports STL / 3MF / OBJ with repair.
- A guided tour and an illustrated Quick Start (Help menu).
