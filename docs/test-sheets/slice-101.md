# Test sheet: 0.109.0, Slice 101: Proportions

Time needed: about 10 minutes. (Includes slices 99 and 100 until their pull requests are merged.)

## Get the build

Open the pull request **Slice 101: Proportions (0.109.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a figure sculpted in one piece, standing straight, arms away from its sides.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure; Figure Design → **Proportions** | Pose Figure opens on **3. Proportions**: Ready proportions, and seven sliders at 100 % | |
| 2 | Ready proportions: **Chibi** | The head grows, the body, arms and legs shorten; the skeleton follows | |
| 3 | Ready proportions: **Heroic** | Longer legs, broader shoulders, a slightly smaller head | |
| 4 | Drag Leg length to 130 % and let go | Longer legs; still standing on the plate | |
| 5 | Type 150 in Head size | A bigger head, still joined at the neck; Ready proportions shows "Your own" | |
| 6 | If a part looks wrong: 1. Fit the Skeleton, drag the balls onto the joints, back to 3. Proportions | The parts change where they should | |
| 7 | 2. Pose, choose a ready pose | The figure posed with its new proportions | |
| 8 | Apply | One step in its history ("posed, …, new proportions"); one Undo takes it away | |
| 9 | Undo; Proportions, Chibi only, Apply | The step is called "Proportions" | |
| 10 | Select it, Proportions again | It opens on the same step, its sliders where you left them | |
| 11 | Save, close, open | The same proportions | |
