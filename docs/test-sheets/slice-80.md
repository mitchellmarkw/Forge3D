# Test sheet: 0.89.0, Slice 80: Pictures for sharing

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 80: Pictures for sharing (0.89.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a figure, painted if you have one.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Print/Save tab → **Picture** | A window: Make, Size, Background (each label on top of its box), Seen from, Looking down, Model fills, the shadow tick; a preview of the figure, lit, in its colours and paint, with a soft shadow | |
| 2 | Seen from 0, then 90, then 180 | The front, its left side, its back | |
| 3 | Looking down 0, then 45 | Level with it, then from above | |
| 4 | Model fills 50 % | Smaller in the picture | |
| 5 | Background White, Dark, Clear | Each; Clear shows a checkerboard behind (see-through) | |
| 6 | Untick the shadow | No shadow on the ground | |
| 7 | Size Square 2000; Light grey; **Save...** as a PNG | A progress bar, then "Saved ..."; the PNG opens at 2000 × 2000, sharp, smooth edges | |
| 8 | Clear background; save a PNG; put it over something in a picture app | See-through round the figure (the shadow soft and see-through too) | |
| 9 | Make: **A turntable** | Size changes to the GIF sizes; "Pictures in one turn", "Once round in" and "Turn the preview" appear | |
| 10 | Tick Turn the preview | The preview goes round | |
| 11 | 600 × 600, 36 pictures, 6 s; Save... as a GIF | A progress bar; a GIF that goes smoothly once round in about 6 seconds and loops, with no flicker in the colours | |
| 12 | Save another; Stop part way | "Stopped; nothing saved." | |
| 13 | Select one shape first, then Picture | Only that shape | |
| 14 | Help → Figure, Toy and Kit Tools | A "Picture" section | |
