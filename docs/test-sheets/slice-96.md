# Test sheet: 0.104.0, Slice 96: Toy joint recipes

Time needed: about 15 minutes. (Includes slice 95 until its pull request is merged.)

## Get the build

Open the pull request **Slice 96: Toy joint recipes (0.104.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a figure sculpted in one piece, standing straight, arms away from its sides.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Figure Design → Cut into Parts | Under "Where to cut": **Usual Figure**, **Super Poseable**, **No Cuts** | |
| 2 | Joint: Left shoulder; Cut here; open Joint type | Butterfly shoulder can be chosen; Drop-down hip, Ankle rocker and Ab crunch are greyed out | |
| 3 | Joint: Waist; open Joint type | Only Ab crunch of the four can be chosen | |
| 4 | Super Poseable | The summary lists 12 cuts: neck ball, waist ab crunch, butterfly shoulders, drop-down hips, double elbows and knees, ankle rockers | |
| 5 | Apply | Pieces including Left/Right shoulder block, Left/Right hip block, Left/Right ankle block and Waist block, plus pins and links | |
| 6 | Move a shoulder block away | A hinge fork in the chest where it was; the block has a tab and the shoulder's ball | |
| 7 | Look at an ankle block | A hinge each side, their pins at right angles | |
| 8 | Look at the waist | A swivel between the pelvis and the waist block, a hinge between the block and the chest | |
| 9 | Undo | The figure in one piece again | |
| 10 | Usual Figure; Apply | As before (no blocks) | |
| 11 | Print a shoulder (chest, block, upper arm and pin) and put it together | The arm swings forward on the block and turns on the ball | |
