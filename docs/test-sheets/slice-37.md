# Test sheet: slice 37, Dark theme (0.46.0 Beta)

Time needed: about 5 minutes.

## Get the build

Open the pull request **Slice 37: Dark theme (0.46.0)**, open its Windows build check,
download the `Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

## Checks

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Start it | Light or dark to match Windows' app mode (Settings → Personalisation → Colours → Choose your app mode) | |
| 2 | **View → Theme** | Follow Windows (ticked), Light, Dark | |
| 3 | Choose **Dark** | At once: dark menus, ribbon, panels and status bar; a dark 3D view with a grid you can still see; light ribbon icons | |
| 4 | Look round: each ribbon tab, the Objects list, Properties with a shape selected, a few panels (Hole, Shell, Measure, Section View) | Everything readable; nothing left white; greyed-out buttons look greyed out | |
| 5 | **Sketch** on the plate; draw a rectangle and a dimension | Dark paper and grid, bright lines; the dimension's box readable | |
| 6 | Measure between two shapes | The label in the view is dark with light writing | |
| 7 | Help → Take the Tour, one step | A dark note, readable. Skip the tour | |
| 8 | Close and start again | Still dark | |
| 9 | View → Theme → **Light** | Back to light at once, everything as it was before | |
| 10 | View → Theme → **Follow Windows**; switch Windows' app mode, then restart Forge3D | It follows Windows | |

## Send back

"All pass" or the failures (with the number).
