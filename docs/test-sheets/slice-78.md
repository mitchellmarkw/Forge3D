# Test sheet: 0.87.0, Slice 78: Instruction sheets

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 78: Instruction sheets (0.87.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a jointed figure in separate parts (Cut into Parts), and a kit made with Kit Layout if you have one.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Tools → **Parts List...** | A **#** column first: 1, 2, 3... down the parts | |
| 2 | Close it; Print/Save tab → **Instruction Sheet** | A window with Title, View from (label on top of the box), Pull apart, two ticks, Paper (label on top), Notes, and a preview on the right | |
| 3 | Look at the preview | The parts pulled apart, outlined, each with a numbered balloon pointing at it; the numbers match the Parts List | |
| 4 | Change View from: Front, Left, Right, Back, Top | The preview turns to each; balloons stay clear of the parts and each other | |
| 5 | Pull apart 0 %, then 120 % | Together as built, then spread well apart | |
| 6 | Make the window bigger | The preview grows to fit | |
| 7 | Type a few lines in Notes; **Save as PDF...** | "Saved ..." under the notes | |
| 8 | Open the PDF | The title, "N parts · exploded view: ...", the picture with balloons, the parts list (#, Part, Size), "Putting it together" with your notes | |
| 9 | Zoom in on the PDF | Balloons and numbers sharp; the picture clean at normal zoom | |
| 10 | Paper A4; save again | An A4 page | |
| 11 | Untick "A parts list under the picture"; save | A bigger picture, no table | |
| 12 | A kit (Kit Layout, merged): tick "The parts inside joined shapes" | Each part in the kit numbered (and the frame), the kit itself not | |
| 13 | Select two shapes first, then Instruction Sheet | Only those two | |
| 14 | Help → Figure, Toy and Kit Tools | An "Instruction Sheet" section | |
