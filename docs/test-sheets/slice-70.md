# Test sheet: 0.79.0, Slice 70: Hand Ports

Time needed: about 20 minutes.

## Get the build

Open the pull request **Slice 70: Hand Ports (0.79.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a forearm, two hands and an accessory (a sword or a gun), each a shape of its own.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the forearm, Features tab → **Hand Ports** | The panel: "Joint standard:" and "What to add:" with their labels right on top; "A peg" chosen; Shape, Diameter, Length, End | |
| 2 | Click the end of the forearm | A gold peg stands straight out of the surface there; the line under the panel describes it | |
| 3 | Change Shape to Hexagon, then Turned | "Diameter" becomes "Across flats"; the peg turns six-sided and turns round its axis | |
| 4 | End: **Ball (for a ball-jointed wrist)** | A "Ball size:" box; a ball on the peg's end | |
| 5 | Back to Round, Chamfered; **Apply** | The peg joined to the forearm; the history says "Round peg Ø3 × 4 (chamfered)" | |
| 6 | Select a hand (named with "hand" in it), Hand Ports | "The socket for the peg (in a hand)" chosen, with "Printed on:" and "Fit:" | |
| 7 | Click the hand's wrist, Apply | A peg hole cut straight in (red before Apply) | |
| 8 | Print the forearm and hand (or check in your slicer) | The peg goes into the hand and holds | |
| 9 | Select the other hand, Hand Ports, **A grip hole**; click where a handle would go in | A red rod straight through the hand | |
| 10 | "Clicking the hand sets:" **The way out**; turn the view and click where it comes out | The hole aims between the two clicks; **Straight In** puts it back | |
| 11 | Apply; double-click the grip hole in the history; change Handle diameter | The panel opens with its settings; Apply changes the hole | |
| 12 | Select the accessory, Hand Ports, A peg sized to the grip (Handle diameter), long enough for a handle | A handle that fits the grip hole | |
| 13 | **Save to Standard...** with a peg set up; name it "Wrist peg" | It's kept (Tools → Joint Standards shows it); next time it's in the "Joint standard:" list and choosing it sets the sizes | |
| 14 | Undo, Redo | Each port comes and goes in one step | |
| 15 | Save, close, open again | The pegs and holes come back the same | |
| 16 | Help → Figure, Toy and Kit Tools | A Hand Ports section under Joints | |
