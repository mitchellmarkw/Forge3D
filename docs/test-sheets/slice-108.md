# Test sheet: 0.116.0, Slice 108: Brick figure, reworked

Time needed: about 15 minutes, plus a test print if you like.

## Get the build

Open the pull request **Slice 108: Brick figure, reworked (0.116.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use the figure whose head was cut above the mouth last time.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure; Brick Figure | A panel on the right; the figure see-through with an orange disc at the neck | |
| 2 | Look at the disc from the side | Under the chin, where the neck's narrowest, not through the face | |
| 3 | Cut higher by 2, then -2 | The disc moves up, then down the neck | |
| 4 | Tip forward 15 | The disc tilts, lower at the front; set it back to 0 | |
| 5 | Build as Parts; Height 60; Make Brick Figure | Six shapes beside the figure; the panel closes | |
| 6 | Hide the figure; look at the brick figure from the front and side | Torso narrower at the shoulders than the waist; square legs, flat fronts; arms angled out and bent forward; C-shaped hands | |
| 7 | Look at the head from the side and the top | All the head (chin included), sitting square on the torso, not too far forward | |
| 8 | Hide the head | A post on the torso; the head has a socket underneath (a collar round it if the neck was thin) | |
| 9 | Hide the legs; look under the hips | A lug between the legs with an axle out each side; each leg has a hole on its inside for it | |
| 10 | Hide an arm | A peg out of the shoulder; the arm's hole on its inside only | |
| 11 | Undo; Brick Figure; Head forward by -2; Make | The head sits 2 mm further back | |
| 12 | Undo; Build as One piece; Make | One shape, Brick figure, 60 mm tall | |
| 13 | Grip holes None | Solid hands, no C | |
| 14 | Esc while the panel is open | It closes; nothing made | |
| 15 | Figure Style → Bobblehead, cut ticked, a flat cut | The disc under the chin there too | |
| 16 | Optional: print the parts at 60 mm and put them together | Arms press onto pegs, legs onto the axle; both turn; the head turns on its post | |
