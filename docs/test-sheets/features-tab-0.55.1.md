# Test sheet: Features tab (0.55.1 Beta)

Time needed: about 5 minutes.

## Get the build

Open the pull request **Features tab (0.55.1)**, open its Windows build check, download
the `Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

## Checks

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Look at the ribbon's tabs | Build, Design, **Features**, Sculpt, View, Print/Save. Forge3D opens on the tab you last used in 0.55.0 | |
| 2 | Open **Design** | Combine, Arrange, Sketch, Change (Split, Emboss) and Place: no Hole, Thread or Shell any more, and it fits without scrolling | |
| 3 | Open **Features** | **Holes and Joints**: Hole, Thread, Quick Socket. **Surface**: Shell, Follow, Edges. **Repeat**: Pattern | |
| 4 | Select a shape and try each Features button | Each opens its tool as before | |
| 5 | Leave Forge3D on the Sculpt tab, close it and open it again | It opens on Sculpt | |
| 6 | Help → **Take the Tour** | The "Words and pictures" step mentions the Features tab; the "Ready to print" step points at Send to Slicer on Print/Save | |
