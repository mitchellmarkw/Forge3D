# Test sheet: 0.88.0, Slice 79: Sewing patterns

Time needed: about 20 minutes.

## Get the build

Open the pull request **Slice 79: Sewing patterns (0.88.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a figure in one piece, standing in a T-pose or with the arms out (a sculpted one is best).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Sculpt → Paint: paint a shirt or jacket on the body and upper arms in one colour (all the way round); Done | The figure painted | |
| 2 | Select it; Print/Save tab → **Sewing Pattern** | The window opens straight away with "Laying it flat..." then the pieces appear on the right | |
| 3 | Look at the left side | Painted colour (label on top of the box, a swatch of your colour), Seams (label on top), Seam allowance, Paper (label on top), and "2 pieces; laid flat, most lengths are within N% of the figure's" | |
| 4 | Look at the pieces | A Front and a Back, shirt-shaped with the sleeves out to the sides, upright; a solid cutting line, a dashed stitching line inside it, a grain arrow and the piece's name | |
| 5 | Seam allowance 6 mm | The solid line moves further out; the dashed line stays | |
| 6 | Seams: Left and right | A Right and a Left piece instead | |
| 7 | Seams: One piece | A warning that it goes all the way round (or stretches a lot) | |
| 8 | Back to Front and back; **Save as PDF...**; print it at 100% (Actual size) | The square measures 50 mm; the pieces are full size for the figure | |
| 9 | Cut the front and back out of paper on the solid line and tape them round the figure | They wrap the painted area, meeting at the sides | |
| 10 | **Save as SVG...**; open it in a browser or Inkscape | The same pieces, sized in millimetres | |
| 11 | Paint a cape on the back only (another colour); Sewing Pattern; choose that colour; Seams: One piece | One piece, close to flat (a small %) | |
| 12 | A figure with no paint: Sewing Pattern | A message to paint the clothes on first | |
| 13 | Help → Figure, Toy and Kit Tools | A "Sewing Pattern" section | |
