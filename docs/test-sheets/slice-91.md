# Test sheet: 0.99.0, Slice 91: A tidier ribbon

Time needed: about 10 minutes.

## Get the build

Open the pull request **Slice 91: A tidier ribbon (0.99.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.
