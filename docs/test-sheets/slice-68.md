# Test sheet: slice 68, Cut into Parts (0.77.0 Beta)

Time needed: about 30 minutes (plus prints, if you do 18–19).

## Get the build

Open the pull request **Slice 68: Cut into Parts (0.77.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

You'll need a figure sculpted in one piece (or an imported STL of one), standing straight and facing the front,
arms away from its sides. Save a copy first.

## Setting it up

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure, Sculpt tab → **Cut into Parts** | The figure goes see-through with the orange skeleton in it; the panel: 1. Check the skeleton, 2. Where to cut | |
| 2 | **Usual Figure** | Red discs at the neck, shoulders, hips, elbows and knees, each square to its limb; "Cuts (9):" lists them | |
| 3 | Look from the front, then the side; drag any ball that isn't in the middle of its joint (the hips especially: put them where the legs meet the body) | The ball follows the mouse (its partner too, with Move both sides together); when you let go, its disc moves with it | |
| 4 | Click a ball (or choose in **Joint:**) | Joint (label right on top of its drop-down) shows that joint; the line under Joint type says what goes there, its size, and how thick the limb is | |
| 5 | Change a joint's **Joint type** (label on top) to Double hinge, Swivel, Just cut | The list of cuts follows; with both sides together, the other side changes too | |
| 6 | Tick **Cut here** at a wrist, untick it at a knee | A disc appears at the wrist and goes from the knee | |
| 7 | With a joint standard in use (Tools → Joint Standards), open Cut into Parts | Joint type lists "Standard: …" joints too | |
| 8 | **Place It Again**, **No Cuts** | The skeleton goes back; the cuts are cleared | |

## Cutting

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 9 | Usual Figure, balls placed, **Apply** | Wait for it (note how long). The figure in pieces, selected, named Torso, Head, Left upper arm, Left forearm, Left thigh, Left lower leg... and hinge pins listed beside them | |
| 10 | Move each piece away to look | Shoulders, hips and neck: a ball on a neck on the torso, a snap-in socket in the limb (or head). Elbows and knees: a fork in the upper piece, a tab on the lower one, a pin hole through both | |
| 11 | Look at the pins | Across each elbow and knee, about as long as the limb is wide, so it bends forwards and back | |
| 12 | One Ctrl+Z | The figure back in one piece | |
| 13 | Ctrl+Y, then **Pose Test** | The joints are listed; dragging an arm or leg turns it at its joint | |
| 14 | Double-click a piece's Hinge or Socket step in Objects | It opens in Quick Hinge / Quick Socket, to change the size | |
| 15 | Save, close, open | The pieces and their joints are there | |
| 16 | Cut with a joint standard's ball at the shoulders | The shoulder balls are the standard's size | |
| 17 | On one of your heavy sculpts: Usual Figure, Apply | Note how long it takes; nothing goes missing (every piece has its surface) | |
| 18 | (Optional) Print the pieces | The balls snap into the sockets; the pins go through the hinges; it holds together | |
| 19 | (Optional) Tell me which joints were too stiff, too loose, or cut in the wrong place | | |
