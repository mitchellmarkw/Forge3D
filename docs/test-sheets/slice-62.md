# Test sheet: slice 62, Kit layout (0.71.0 Beta)

Time needed: about 10 minutes.

## Get the build

Open the pull request **Slice 62: Kit layout (0.71.0)**, open its Windows build check,
download the `Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

## Checks

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Add five small shapes anywhere; **Tools → Kit Layout…** | The dialog: Parts (label on top of its drop-down), Gap 4, Frame bars 2, Gates 0.80, Number the parts, Number height 3, Join ticked | |
| 2 | Parts: Everything on the plate; **Make Kit** | One "Kit 1" shape: a frame with bars between rows, each part joined to a bar by a thin gate, a numbered tag by each | |
| 3 | Look from the top; zoom in on a tag | The parts clear of each other and the bars; the numbers readable | |
| 4 | Expand Kit 1 in Objects | The frame and the parts, renamed "1 …", "2 …" | |
| 5 | Undo | Everything back where it was, with its old name | |
| 6 | Select two shapes; Kit Layout with "The 2 selected shapes", Join unticked, no numbers | Just those two on a frame; the frame a shape of its own | |
| 7 | Some of your small figure parts (hands, accessories) | A kit you'd print; gates thin enough to twist off | |
| 8 | Print it | Parts come off the gates cleanly | |
