# Test sheet: slice 15, Quick start (0.24.0)

Time needed: about 15 minutes (most of it following the guide).

## Get the build

Open the pull request **Slice 15: Quick start (0.24.0)**, open its Windows build check,
download the artifact, unzip and run `Forge3D.exe`. **Help → About** says 0.24.0.
