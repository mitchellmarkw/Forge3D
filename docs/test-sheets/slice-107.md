# Test sheet: 0.115.0, Slice 107: Brick figure

Time needed: about 15 minutes, plus a test print if you like.

## Get the build

Open the pull request **Slice 107: Brick figure (0.115.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a one-piece figure standing straight (the same one as before).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Figure Design tab | A **Brick Figure** button after Accessories | |
| 2 | Select the figure; Brick Figure | A window: Build as (label right on top of its list), Height (the figure's height), Head size 100%, Fit 0.15, Grip holes 3.0 | |
| 3 | Height 60; Make Brick Figure | Six new shapes beside the figure: Brick head, torso, left arm, right arm, left leg, right leg | |
| 4 | Hide the figure; look round the brick figure | The figure's own head on a block body: square legs with feet, hips, a torso with rounded shoulders, arms with round hands | |
| 5 | Look at the hands from above | A round hole down through each | |
| 6 | Hide the head | A round post on top of the torso; the head (show it, hide the torso) has a socket underneath | |
| 7 | Hide an arm | A peg sticking out of the shoulder; the arm has a hole on its inside only (none showing outside) | |
| 8 | Hide a leg | A peg out of the side of the hips; the leg's hole is on its inside only | |
| 9 | Undo once | All six brick shapes go | |
| 10 | Brick Figure; Build as One piece; Make | One shape, **Brick figure**, 60 mm tall | |
| 11 | Undo; Brick Figure; Head size 140% | A bigger head on the same body | |
| 12 | Grip holes None | Solid hands | |
| 13 | Height 20, Grip holes 3 | A message that the grip hole is too big for the hands | |
| 14 | Optional: print the parts at 60 mm and put them together | The arms and legs press onto their pegs and turn; the head sits on its post and turns | |
