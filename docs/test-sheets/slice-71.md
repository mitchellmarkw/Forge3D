# Test sheet: 0.80.0, Slice 71: Make Hand

Time needed: about 20 minutes.

## Get the build

Open the pull request **Slice 71: Make Hand (0.80.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select a figure or an arm, Sculpt tab → **Make Hand** | The panel, each drop-down's label right on top of it; a see-through pair of fists beside the selection | |
| 2 | Pose: try **Open**, **Relaxed**, **Pointing**, **Fist** | The preview changes after a moment each time; the thumb is on the inner side of each hand (towards the body's middle as the figure faces you) | |
| 3 | **Gripping** | A "Handle" box: Handle diameter, Fit, Angle; the fingers wrap round the handle's size | |
| 4 | Change Handle diameter (e.g. 2 then 5 mm) | The fingers wrap looser or tighter | |
| 5 | Scale: 1:6, 1:18 | Hand length changes (31.5 mm, 10.5 mm); typing a length sets Scale to "Set the length" | |
| 6 | Fullness 100% then 160% | Thin, lifelike fingers; then chunkier ones | |
| 7 | Which hand: Right, Left | One hand, mirrored for the left | |
| 8 | Socket: For a peg / For a ball / None | The sizes change to match; with a bigger peg the wrist grows | |
| 9 | Gripping, a pair; **Make** | "Right hand (gripping)" and "Left hand (gripping)" standing on the plate; their history shows the socket and the grip hole | |
| 10 | Look under a hand's wrist and through the grip | The socket's hole in the wrist; a round hole through the fist along the handle's line | |
| 11 | Double-click the grip hole in a hand's history; change its size | Hand Ports opens; the hole changes | |
| 12 | Undo | Both hands go in one step | |
| 13 | Print a hand and the forearm with Hand Ports' peg (same sizes) | The hand goes on the peg and holds; a handle of the diameter set fits the grip | |
| 14 | Help → Figure, Toy and Kit Tools | A Make Hand section | |
