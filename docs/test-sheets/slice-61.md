# Test sheet: slice 61, Split for painting (0.70.0 Beta)

Time needed: about 10 minutes, plus a print (check 7) when you can.

## Get the build

Open the pull request **Slice 61: Split for painting (0.70.0)**, open its Windows build
check, download the `Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

## Checks

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Add a Cylinder; Design tab → **Split by Mask** | Under Keep: **Alignment keys on the cut** (ticked) and **Key fit** 0.10 mm | |
| 2 | Paint over the top part (brush 8 mm), Apply | Two pieces; Objects says "…, keyed)" | |
| 3 | Move the painted piece up and aside | A three-sided hole in the rest's cut; a matching peg on the painted piece's underside | |
| 4 | Double-click a piece; untick the keys; Apply | Both pieces lose their key and hole | |
| 5 | Double-click again; tick the keys, fit 0.2; Apply | Both get them back, the hole a little bigger | |
| 6 | One of your figures: paint a hand or a belt off, Apply | A key on each cut big enough for one | |
| 7 | Print a keyed pair | The peg goes in one way only, snug | |
| 8 | Save, close, open | The keys are still there | |
