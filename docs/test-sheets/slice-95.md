# Test sheet: 0.103.0, Slice 95: Make Part from paint

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 95: Make Part from paint (0.103.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a figure (or a Sphere 40 mm across).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure; Figure Design → **Make Part** | The painting panel, titled "Make a part on …": **The new part:** (label above the list), Thickness, Fit; no cut, joint or key options; the button says **Make Part** | |
| 2 | Paint a chest plate on the torso; Sits on top, 1.5 mm, fit 0.1; Make Part | A new shape "… part" over the chest, following its curves and the paint's edge; the figure unchanged | |
| 3 | Hide the part | The chest as it was | |
| 4 | Look closely at the part's edge and inside face | It sits over the chest with a small even gap | |
| 5 | Undo | The part gone | |
| 6 | Make Part again on the same area, **Set into the body (flush)** | The part's outer face where the chest was (the outline unchanged); hide it and the chest is cut back under it | |
| 7 | Sculpt the new part (Sculpt tab) | It sculpts as a shape of its own | |
| 8 | Paint a glove round a hand or a belt round the waist; Make Part | A ring-shaped part all the way round | |
| 9 | Make Part with nothing painted | "Paint where the part goes first." | |
| 10 | Paint the whole shape; Make Part | A plain message (it's made over a painted area only); nothing changed | |
| 11 | Save, close, open | The part and the cut-back body as they were | |
| 12 | Close and open Forge3D; Make Part | Your last placement, thickness and fit are kept | |
