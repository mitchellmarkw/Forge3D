# Test sheet: 0.117.0, Slice 109: Brick figure preview and head mask

Time needed: about 10 minutes.

## Get the build

Open the pull request **Slice 109: Brick figure preview and head mask (0.117.0)**, open its Windows build check,
download the `Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select your figure; Brick Figure | After a moment, a gold brick figure beside your figure, where it will be made | |
| 2 | Change Height, Head size, Head forward by, Cut higher by | The gold figure follows each change (a moment after you stop) | |
| 3 | Build as One piece, then back to Parts | The preview follows | |
| 4 | Untick Show the brick figure beside the figure | The gold figure goes; tick it again and it's back | |
| 5 | Choose the head by: A mask painted over the head | The disc and its boxes go; "Nothing painted yet"; the preview goes until it's painted | |
| 6 | Paint the Head... | Mask painting on the figure, with a Use This Mask button | |
| 7 | Front view; click Lasso; draw round the head just above the shoulders; Use This Mask | Back in Brick Figure, "Painted (1 stroke)", the preview with the painted head | |
| 8 | Paint the Head... again | The paint from before is still there; add or rub some out; Use This Mask | |
| 9 | Paint the Head...; press Esc | Back in Brick Figure; the mask as it was | |
| 10 | Paint the Head...; Clear; paint a dab on a foot only; Use This Mask | A red line saying the mask isn't over the head | |
| 11 | Paint the head properly; Make Brick Figure | Six shapes beside the figure, where the preview was; the head as painted | |
| 12 | Undo; Brick Figure; Make with the flat cut | Still works as before | |
