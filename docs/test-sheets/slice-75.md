# Test sheet: 0.84.0, Slice 75: Will it stand?

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 75: Will it stand? (0.84.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a jointed figure (Cut into Parts or Quick Hinge/Socket joints) standing on both feet.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Design tab → **Will It Stand?** | Pose Test opens with "Show the balance" ticked: a gold ball (the centre of weight) with a line down to the ground, and a green patch round the feet | |
| 2 | Read the line under the tick | "It stands: it can lean N° before it tips..." and how many places it touches the ground | |
| 3 | Pose a leg forward (or lift one), as far as it goes | The patch and the ball follow as you pose; it turns red and says how far outside it is if it would tip | |
| 4 | Lean the torso or put the arms out to one side | The gold ball moves that way | |
| 5 | Untick Show the balance | The ball and patch go | |
| 6 | Back to the Build Pose; set Stand peg Ø and Hole depth; **Peg Hole in Each Foot** | A message saying how many holes; each foot's history shows a "Round peg socket" step | |
| 7 | Look under the feet | A round hole up into the middle of each sole | |
| 8 | Undo | Both holes go (one step) | |
| 9 | A one-piece figure (not jointed): Will It Stand?; Peg Hole in Each Foot | Each foot counted on its own; a hole in each sole, not between them | |
| 10 | Print a foot (or check in your slicer) on a stand peg of that size | The peg fits the hole | |
| 11 | Help → Figure, Toy and Kit Tools | A "Will it stand?" section | |
