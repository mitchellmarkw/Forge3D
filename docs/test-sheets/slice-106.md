# Test sheet: 0.114.0, Slice 106: Figure styles, refined

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 106: Figure styles, refined (0.114.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use the same one-piece figure as last time.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure; Figure Style | The styles are Bobblehead, Vinyl collectible and Caricature (no Blocky); no Blocky slider | |
| 2 | Vinyl collectible at 100% | About what 50% looked like last time | |
| 3 | Drag Strength to 200% | About what 100% looked like last time | |
| 4 | Caricature at 100% | Gentler than last time (last time's 50%) | |
| 5 | Bobblehead | A big head; look at the neck just under it from the side | The neck keeps its own thickness up to the head: no flare or lip | |
| 6 | Tick Cut the head off to sit on a spring; Where the head comes off: A flat cut at the neck | An orange disc across the neck, and Cut higher by / Tip forward boxes | |
| 7 | Cut higher by 3, then -3 | The disc moves up, then down the neck | |
| 8 | Tip forward 20 | The disc tilts, lower at the front | |
| 9 | Set it back to 0 and 0; Spring diameter 20 | A red warning that the neck's too thin there | |
| 10 | Spring diameter 5; Apply | Two shapes, **Head** and **Body**; the head comes off where the disc was | |
| 11 | Hide the Head | A post on the neck; the bottom of the head (show it, hide Body) clean, with a socket | |
| 12 | Undo once | The figure as it was before the style | |
| 13 | Figure Style → Bobblehead; Where the head comes off: Paint a mask over the head after Apply; Apply | The styled figure opens in mask painting, with a **Cut Off Head** button | |
| 14 | Turn to the Front view; click Lasso; draw round the head, just above the shoulders | The head painted dark | |
| 15 | Cut Off Head | **Head** and **Body**, cut flat where the paint stopped, socket and post in | |
| 16 | Undo once | The figure in one piece, styled (the style is its own step) | |
| 17 | Figure Style again on a styled figure | The style shown is the one used; the cut settings start at 0 | |
| 18 | Proportions → Heroic, Chibi | Still work; Chibi's big head has no lip under it either | |
| 19 | Open a file saved with 0.113.0 that used Blocky | Opens; the figure without the squaring | |
