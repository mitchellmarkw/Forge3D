# Test sheet: 0.108.0, Slice 100: Accessory makers

Time needed: about 15 minutes. (Includes slice 99 until its pull request is merged.)

## Get the build

Open the pull request **Slice 100: Accessory makers (0.108.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select a figure; Figure Design → **Accessories** | The Accessories panel; a see-through sword in front of the figure; "Make adds a sword, printed 82.4 × 15.0 × 4.5 mm" | |
| 2 | Each combo box | Its label rests right on top of it | |
| 3 | Make | A Sword lying flat on the plate, selected; the panel closes | |
| 4 | Accessories; Blade length 25 cm, Tip Angled | The preview turns into a short angled dagger; Make names it "Dagger" | |
| 5 | Scale 1:6 | Everything about twice as big as at 1:12 (the handle stays 3 mm) | |
| 6 | Shield: Heater, Curve 30%, Boss and Grip bar ticked | A bowed heater shield with a boss in front and a bar on the back | |
| 7 | Shield: Round | Height greys out; a round shield | |
| 8 | Staff or spear: Spear point, then Orb on top | A spear with a leaf point; a staff with an orb | |
| 9 | Belt with buckle: waist 30 × 20 mm | A belt ring with a buckle on the front and a gap at the back; printed about 32 mm across | |
| 10 | Untick "Open at the back" | The ring closes; Gap greys out | |
| 11 | Holster | An open pouch standing up with a loop on the back | |
| 12 | Make Hand, Gripping; put the sword's grip through its hole | It fits (the same 3 mm handle) | |
| 13 | Select the sword; Accessories → Save Selected...; name it "My sword" | It's listed under Your accessories | |
| 14 | Close; Accessories; double-click "My sword" (or Add) | Another copy added at its saved size | |
| 15 | Manage...; rename and delete | As with custom shapes; the folder is Documents\Forge3D\Accessories | |
| 16 | Close Forge3D, open it, Accessories | The last kind and sizes are remembered | |
