# Test sheet: 0.77.2, Cut into Parts: turn each cut by hand

Time needed: about 10 minutes.

## Get the build

Open the pull request **Cut into Parts: turn each cut by hand (0.77.2)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a one-piece figure.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure, Sculpt tab → **Cut into Parts**, **Usual Figure**; click the left shoulder ball | Under Joint type: **Tip forward:** and **Tilt sideways:** (both 0°) and a **Straighten** button | |
| 2 | With **Both sides together** on, set Tilt sideways to 20° | Both shoulder discs tip down at the top, as mirror images of each other | |
| 3 | Set Tip forward to 15° | Both shoulder discs tip towards the front | |
| 4 | Look at the summary | The shoulders listed with "(turned 15°, 20°)" | |
| 5 | Click **Straighten** | Both discs go back upright, the spins back to 0° | |
| 6 | Turn off Both sides together, tilt only the right knee forward 20° | Only the right knee's disc turns | |
| 7 | Tilt a shoulder again, **Apply**; move the arm away | The cut follows the turned disc, the ball joint seated in it | |
| 8 | Look at the right knee hinge | The hinge and its pin are turned with the cut (the pin still runs across the knee) | |
| 9 | Pick a joint set to **Just a cut** and one set to nothing | The tilt spins are greyed out for joints that aren't cut | |
| 10 | Undo, then Redo | The whole cut goes and comes back in one step | |
