# Test sheet: 0.77.1, Cut into Parts cuts the body's way

Time needed: about 15 minutes.

## Get the build

Open the pull request **Cut into Parts: cuts the body's way (0.77.1)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use the same figure that was cut wrongly in 0.77.0 (a copy).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure, Sculpt tab → **Cut into Parts**, **Usual Figure** | The shoulder discs stand upright (square to the body's side), even if the arms hang at a slant; the neck disc and the hip discs are level | |
| 2 | Look at where the balls were placed (front and side) | Each shoulder ball where its arm meets the body; the hip balls at the crotch; elbows, knees and wrists in the middle of the limb | |
| 3 | The line under Joint type at a shoulder | The limb's thickness about as thick as the arm (not the length of the slanted cut) | |
| 4 | Apply; move the arms and legs away | The arms come off at the shoulder with none of the chest; the torso keeps its full width; the legs come off at the crotch | |
| 5 | Elbows and knees | Still cut square to the limb, the hinge pin across it | |
| 6 | **Pose Figure** on an uncut copy | The skeleton's shoulders, hips and knees placed as in 2 | |
| 7 | Try a figure with arms close to its sides, and one in a T pose | Note anything still cut in the wrong place (which joint, which way) | |
