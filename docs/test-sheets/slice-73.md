# Test sheet: 0.82.0, Slice 73: Texture stamps

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 73: Texture stamps (0.82.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a copy of a figure (or a big sphere) and a black-and-white picture of an emblem (white on black).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the shape, Sculpt tab → **Sculpt**, Brush: **Pattern** | Pattern, "Press it:", Pattern size and Turned; each drop-down's label right on top | |
| 2 | Pattern: try **Chainmail**, **Twill (denim)**, **Knitting**, **Leather**, **Cracked stone**, **Wood grain**, **Skin pores**; drag a short stroke with each | Each texture pressed in where you drag, repeating evenly with no seams | |
| 3 | Turned: 45°; drag again | The texture runs at 45° | |
| 4 | Ctrl-drag | It's engraved instead of raised | |
| 5 | Press it: **Once, as a stamp, where you click** | "Pattern size" becomes "Stamp size" | |
| 6 | Pattern: **Your own picture...** (the emblem); Stamp size 15 mm; click the chest | The emblem pressed once, centred where you clicked, 15 mm wide, nothing repeated round it; dragging doesn't add more | |
| 7 | Turned 30°; click elsewhere | A second emblem, turned | |
| 8 | Stamp a texture (Scales, 20 mm) on a thin part like an arm | Only the side facing you is pressed, not the back | |
| 9 | Undo stroke; Done; double-click the Sculpt step | The strokes come back as they were (stamps, turns) | |
| 10 | Save, close, open again | The same | |
| 11 | Help → Figure, Toy and Kit Tools | A Texture stamps section under Detail | |
