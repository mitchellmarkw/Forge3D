# Test sheet: 0.113.0, Slice 105: Figure styles

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 105: Figure styles (0.113.0)**, open its Windows build check, download the
`Forge3D-windows-x64-…` artifact, unzip and run `Forge3D.exe`.

Use a figure sculpted in one piece, standing straight with its arms away from its sides (the one you've used for
Pose Figure is ideal).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Select the figure; Figure Design tab | A new **Figure Style** button next to Proportions | |
| 2 | Click Figure Style | Pose Figure opens on **4. Style**; the four stage buttons sit two to a row, their names whole | |
| 3 | Figure style: **Bobblehead** | The head grows big, the body a little smaller; a line says what it does; a Bobblehead spring box shows | |
| 4 | Figure style: **Vinyl collectible** | A huge head, short chunky body, stubby thick arms and legs; the spring box goes | |
| 5 | Figure style: **Caricature** | A bigger head; anything already long on your figure (arms, legs) a little longer still | |
| 6 | Figure style: **Blocky** | The figure squared off all over (flat sides, corners), a little bigger | |
| 7 | Drag Strength to 50%, then 150% | Half as far, then further than the style | |
| 8 | Back on Vinyl collectible, set Blocky to 40% | Vinyl, squared off a bit | |
| 9 | Click 3. Proportions | The sizes the style set, with **Limb thickness** and **Body width** at the bottom; change one and it follows | |
| 10 | Click 2. Pose, choose a ready pose; Apply | The posed figure in its style; the step is named **Vinyl collectible** | |
| 11 | Double-click the step in Objects, then 4. Style | It shows Vinyl collectible at the strength you used | |
| 12 | Choose None (as it was made) | Back to the figure's own proportions; Cancel | |
| 13 | Undo until the figure is as made; Figure Style → Bobblehead; leave **Cut the head off to sit on a spring** ticked (5 mm spring); Apply | Two shapes: **Head** and **Torso** | |
| 14 | Hide the Head (its eye) | A small round post sticking up from the neck; no wide lip round the cut | |
| 15 | Show the Head; hide the Torso; look from below | A round socket up into the bottom of the head | |
| 16 | Undo once | The figure is back in one piece, as made (the style and the cut are one step) | |
| 17 | Figure Style → Bobblehead, Spring diameter 20 mm; Apply | A message that the neck's too thin for the spring; nothing changes | |
| 18 | Save, close and reopen a file with a styled step | It looks the same; double-click opens on its style | |
| 19 | Open a file saved with 0.112.0 that has Proportions | Unchanged (limb thickness and body width 100%) | |
| 20 | Help → Figure Tools | A **Figure Style** section | |
