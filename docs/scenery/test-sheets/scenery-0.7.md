# Test sheet: Forge3D Scenery 0.7.0 — Rough stone walls

Time needed: about 10 minutes.

## Get the build

Open the pull request **Slice 116: Scenery rough-hewn stone and fieldstone walls (Scenery 0.7.0, Forge3D 0.124.0)**,
open its Windows build check, download `Forge3D-Scenery-windows-x64-…` (and `Forge3D-windows-x64-…` for step 9).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Run Scenery; scale 1:35; New Building; Material: Rough-hewn stone | Plain walls at once, then (a moment later) rough, squared stones in uneven courses, standing out of the mortar; grey-brown | |
| 2 | Course height 500; Stone length 900 | Bigger stones | |
| 3 | Untick Mortar | The stones laid dry, touching | |
| 4 | Material: Fieldstone (irregular) | Rounded stones of every shape in wide mortar lines (a "giraffe" house); only Stone size and Joint shown | |
| 5 | Joint 80 | Wider mortar lines | |
| 6 | Shape: L-shape; Add Door on a wall | The stones follow the L; the door cut through them | |
| 7 | Model scale 1:220 | Plain walls, and a note that the stones are too small to print | |
| 8 | Back to 1:35; Add Building; Export for Printing (3MF) | Opens in your slicer; the stones visible | |
| 9 | Save; open in Forge3D 0.124 | The building shows | |
