# Test sheet: Forge3D Scenery 0.3.0 — Rocks and boulders

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 112: Scenery rock designer (Scenery 0.3.0, Forge3D 0.120.0)**, open its Windows
build check, download `Forge3D-Scenery-windows-x64-…` (and `Forge3D-windows-x64-…` for the last steps).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Run Scenery; scale 1:35; New Rock | A panel on the right (New rock); a rounded boulder on the plate, rough at once, finer a moment later | |
| 2 | Read under the panel | "On the plate: about 42.9 x 31.4 x 20.6 mm, at 1:35" | |
| 3 | Click New Shape a few times | A different boulder each time, the same size; the Number changes | |
| 4 | Type a Number you saw before | That same boulder again | |
| 5 | Drag Roughness to 0, then 100 | Smooth, then lumpy and pitted (it changes when you let go) | |
| 6 | Kind: Crag (broken rock) | A blocky rock with flat faces and sharp edges; the sizes change to a crag's | |
| 7 | Kind: Slab | A flat stone | |
| 8 | Tick Layers; Layer thickness 100 | Grooves across the rock; untick: gone | |
| 9 | Kind: Pile of rocks | A heap of separate rocks; "Rocks in the pile" shows | |
| 10 | Rocks in the pile 20, then 3 | More, smaller rocks; then a few big ones | |
| 11 | Sunk into the ground 0, then 60 | The whole rock, then only its top; the base always flat on the plate | |
| 12 | Esc | The panel closes; nothing made | |
| 13 | New Rock; Add Rock | "Boulder" in Objects, on the plate | |
| 14 | New Rock again; Kind Crag; Add Rock | "Crag" beside the boulder, not on top of it | |
| 15 | Pick the boulder; Change | The panel opens with its settings (Change the rock) | |
| 16 | Height 1500; Update Rock | The same boulder, taller, in the same place | |
| 17 | Ctrl+Z | As it was | |
| 18 | New Building; Add Building; double-click Building in Objects; Material Logs; Update; double-click it again | The panel shows Logs (it kept the change) | |
| 19 | Save; open the file in Forge3D 0.120 | The rocks and building show; move a rock, save; open in Scenery again: Change still works, keeping it where you moved it | |
| 20 | Export for Printing (3MF) | Opens in your slicer; each rock's base flat on the bed | |
