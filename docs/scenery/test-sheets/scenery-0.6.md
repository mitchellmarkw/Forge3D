# Test sheet: Forge3D Scenery 0.6.0 — Building shapes

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 115: Scenery building shapes (Scenery 0.6.0, Forge3D 0.123.0)**, open its Windows
build check, download `Forge3D-Scenery-windows-x64-…` (and `Forge3D-windows-x64-…` for the last steps).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Run Scenery; New Building | The usual brick house, and an orange post at each corner | |
| 2 | Shape: L-shape | An L: a front wing and a side wing up the left, each with its own gable roof, crossing where they meet; Front wing depth and Side wing width shown; five posts | |
| 3 | Wait; zoom in on the inside corner | Bricks run into the inside corner; bonded round the outside ones | |
| 4 | Drag the inside corner's post | The wings get wider or narrower as you drag; the fields follow | |
| 5 | Drag an outside corner's post | The whole building wider or deeper (about its middle) | |
| 6 | Shape: T-shape, then U-shape | A T (bar along the back, stem to the front); a U (open to the front); their fields' names change | |
| 7 | Shape: Courtyard | Wings all round an open middle; eight posts | |
| 8 | Roof: Hip; then Flat | A roof over each wing, joined | |
| 9 | Add Window; click on an inner (courtyard) wall | A window there; the list says "inner …" | |
| 10 | Material: Logs; then Wood planks | The logs cross at the corners; the planks have corner boards | |
| 11 | Width 3000 | The wings shrink to fit (or a message says they don't) | |
| 12 | Add Building; double-click it | It opens as a courtyard, its window there | |
| 13 | Save; open in Forge3D 0.123; open again in Scenery | It shows in Forge3D; Change still works in Scenery | |
