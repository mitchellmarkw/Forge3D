# Test sheet: Forge3D Scenery 0.1.0 (groundwork)

Time needed: about 10 minutes.

## Get the build

Open the pull request **Slice 110: Forge3D Scenery groundwork (Forge3D 0.118.0, Scenery 0.1.0)**, open its Windows
build check, and download **both** artifacts: `Forge3D-windows-x64-…` and `Forge3D-Scenery-windows-x64-…`. Unzip
each and run `Forge3D Scenery.exe` from the second.

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Run Forge3D Scenery | Its own window and icon (hills, a tree and a little house); title "Untitled - 1:35 - Forge3D Scenery 0.1.0 Beta"; a Scenery tab with Model scale; an empty plate the size set in Forge3D | |
| 2 | File → Open a model saved in Forge3D | It shows on the plate as in Forge3D, its shapes listed under Objects | |
| 3 | Orbit, pan, zoom; the view cube; F (Fit All) | All as in Forge3D | |
| 4 | Model scale: pick 1:87 (HO) | The title shows 1:87 | |
| 5 | Type 1:76 in the scale box and press Enter | The title shows 1:76 | |
| 6 | Type nonsense (abc) and press Enter | It goes back to 1:76 | |
| 7 | Close and reopen Scenery | The scale is still 1:76 | |
| 8 | Open a model; File → Save As a new name; open that file in Forge3D | It opens in Forge3D, the same | |
| 9 | File → Export for Printing as 3MF | The file is written; it opens in your slicer | |
| 10 | View → Theme → Dark, then Light | The window and view change; Forge3D follows the same choice next time it starts | |
| 11 | Help → Check for Updates | "You have the newest Forge3D Scenery" (none published yet) | |
| 12 | Help → About Forge3D Scenery | Its version and what it's for | |
