# Test sheet: Forge3D Scenery 0.8.0 — Battlements and towers

Time needed: about 15 minutes.

## Get the build

Open the pull request **Slice 117: Scenery battlements and towers (Scenery 0.8.0, Forge3D 0.125.0)**, open its Windows
build check, download `Forge3D-Scenery-windows-x64-…` (and `Forge3D-windows-x64-…` for the last step).

| # | Do this | You should see | Result |
| --- | --- | --- | --- |
| 1 | Run Scenery; New Building; Material: Stone blocks; Roof: Flat | A stone house, flat roof | |
| 2 | Tick Battlements along the wall tops | The walls rise past the roof, notched (merlons at every corner); the roof inside them, a walkway; Parapet height, Merlon and Crenel widths shown | |
| 3 | Merlon width 1000; Crenel width 300; Parapet height 1500 | The notches follow | |
| 4 | Add Tower; click the front-right corner's post | A round tower on that corner, taller than the walls, battlemented; picked (its outline), its settings shown | |
| 5 | Add Tower; click the middle of the front wall | A tower astride the front wall | |
| 6 | Drag the second tower along the wall, then to the back-left corner | It slides along the wall; near the corner it snaps onto it | |
| 7 | Drag it well away from the building | It stands on its own there | |
| 8 | With it picked: Tower shape Square; Top: Roof | A square tower with a pyramid roof | |
| 9 | Pick the round one: Top: Roof | A cone roof | |
| 10 | Across 3000; Height 9000 | It follows | |
| 11 | Press Delete | The picked tower's gone | |
| 12 | Roof: Gable (battlements on) | A gable roof inside the parapet; the towers through it | |
| 13 | Material: Brick, then Rough-hewn stone, then Logs | Bricks and stones round the round towers too; plain towers for logs | |
| 14 | Shape: Courtyard; add a tower at each outside corner | A small castle | |
| 15 | Add Building; save; open in Forge3D 0.125; open again in Scenery and Change it | It shows in Forge3D; Change opens with the towers and battlements | |
